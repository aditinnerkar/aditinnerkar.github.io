Agentic RAG Knowledge Assistant

Problem

Project-management and cost-calculation teams found past best practices and lessons learned through manual document search, outreach to managers and static Excel reports.

Approach

I designed an agentic text-to-SQL RAG system. A Vanna agent plans and calls tools, a retrieval layer matches each question to schema, documentation and example SQL in a ChromaDB knowledge base, and agent memory keeps past question-to-SQL pairs. Records sit in PostgreSQL, chat runs through OpenWebUI, and Azure OpenAI supplies embeddings and chat models. I compared OpenAI and Azure OpenAI APIs, open-source LLMs (Llama, Mistral) and Hugging Face models on accuracy, latency and cost.

Outcome

Answers return in under 3 seconds. The full stack is containerized with Docker, and the production rollout took 2 days.

    Automated BOM Extraction from CAD Drawings

    Problem

    Cost calculation and manufacturing, welding and assembly planning depended on Bill of Materials data locked inside large, complex CAD drawings.

    Approach

    I explored training open-source computer-vision models (YOLOv8), then settled on Azure Document Intelligence with custom chunking-and-rejoining logic for large files. I also designed and built the whole React front end (Tailwind CSS, Ant Design) from Figma and Excalidraw flows.

    Outcome

    95%+ extraction accuracy across ~1,000 drawings, in a three-screen workflow: upload, editable BOM review with interactive preview, and Excel/CSV export. The proof of concept led BENTELER to commission the RAG project above.
